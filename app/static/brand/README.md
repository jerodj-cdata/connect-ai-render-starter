# Brand assets

Logos used by the chat page, copied unmodified from their owners' official
sources. They are trademarks of their owners and are **not** covered by this
repository's MIT license. Use them only to refer to CData and Render, per
each company's brand guidelines.

| File | Source |
| --- | --- |
| `cdata-logotype-depth.svg` | CData brand assets (logotype, Depth `#15151C`), for light backgrounds |
| `cdata-logotype-clarity.svg` | CData brand assets (logotype, Clarity `#F1EEE9`), for dark backgrounds |
| `cdata-monogram-depth.svg` | CData brand assets (monogram, Depth), used as the tab icon |
| `render-mark.svg` | Render, `https://render.com/brand/render_1105076560.svg` |

The page's colours come from the CData Brand Guidelines (Feb 2026): Clarity
`#F1EEE9`, Depth `#15151C`, Agility `#FFE500`, Resolve `#002660`, Balance
`#B5B9BC`. Its fonts are DM Sans and DM Mono where installed, falling back to
the kit's approved web-safe Arial and Courier New.
